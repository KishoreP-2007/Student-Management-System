# Student Management System

A simple Student Management System built using Node.js, Express.js and JSON file storage.

## Technologies

- Node.js
- Express.js
- HTML
- CSS
- JavaScript
- JSON
- Git
- GitHub
- Azure VM
- GitHub Actions
- Nginx
- PM2

## Project Structure

student-management/
│
├── data/
│   └── students.json
│
├── public/
│   └── index.html
│
├── routes/
│   └── studentRoutes.js
│
├── app.js
├── package.json
├── .gitignore
└── README.md

## Features

- View all students
- View student by ID
- Add student
- Update student
- Delete student
- JSON-based data storage
- REST API
- Health check endpoint
